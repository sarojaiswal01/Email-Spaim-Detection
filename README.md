# 📧 Email Spam Detection System

An AI/ML-based Email Spam Detection project built using Python and Machine Learning.  
This application detects whether an email/message is **Spam** or **Not Spam (Ham)** using Natural Language Processing (NLP) techniques.

---

## 🚀 Features

- Detects spam emails/messages
- Machine Learning based prediction
- Simple and user-friendly interface
- Text preprocessing using NLP
- High accuracy model
- Trained using real spam dataset

---

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- NLP (Natural Language Processing)
- Pickle
- Streamlit / Flask (if used)
